# seminar-doc-builder-0603

## トリガー設計
このスキルは以下のワードが含まれるリクエストで起動する。他の汎用スキルや資料作成スキルとの誤発火を防ぐため、**「セミナー」と「企画」または「案内資料」が同時に含まれる場合**に限定する。

- `セミナーの企画と案内資料`
- `セミナー企画と案内資料`
- `セミナーの企画書と案内資料`
- `セミナーの企画・案内資料`
- `セミナー案内資料の作成`（＋企画の意図が文脈にある場合）

## 概要
指定されたテーマのセミナーについて、以下の2ファイルを生成してカレントディレクトリに保存し、開発ブランチへコミット・プッシュする。

1. **企画書** (`kikakusho_<slug>.html`) — 主催者・運営者向けの内部資料
2. **案内ページ** (`annai_<slug>.html`) — 参加者向けの告知・申込み資料

`<slug>` はテーマを英数字・アンダースコアで表した短いラベル（例: `40_50_diet`, `iphone_beginner`, `asset_management`）。

## ステップ 1: 入力情報の確認

ユーザーのメッセージから以下を読み取る。不足している場合はデフォルト値を使う。

| 項目 | 読み取り先 | デフォルト値 |
|------|-----------|-------------|
| テーマ | ユーザー指定 | （必須・必ず特定する） |
| 対象者 | ユーザー指定 | 一般社会人（20〜60代） |
| 開催形式 | ユーザー指定 | 会場参加＋オンライン（ハイブリッド） |
| 定員 | ユーザー指定 | 30名 |
| 参加費 | ユーザー指定 | 一般 3,000円 / 早期 2,000円（カンマ区切り＋「円」表記） |

## ステップ 2: 企画書ファイルの生成

ファイル名: `kikakusho_<slug>.html`

以下の7セクションを**必ずこの順序で**生成する。各セクションはカード（白背景・角丸16px・淡い影）で包み、左に連番の丸バッジを置く。

### セクション構成

**① 開催概要**
日時／形式／定員／参加費／対象／持参物 を 2列テーブル（`th` 幅28%）で表示。

**② 背景・なぜ今やるのか**
テーマの社会的背景・課題感を2〜3文の段落で記述。`<p>` タグ複数。

**③ 受講後のゴール（BEFORE → AFTER）**
左右2カラム＋中央矢印の構成。
- BEFORE カード: 背景 `#f5f0e6`、ボーダー `#d8ccb4`
- 中央矢印: `→`（山吹色・font-size 26px）
- AFTER  カード: 背景 `#e8f0f8`、ボーダー `#a4c0dc`
- 各カードに `ba-label`（BEFORE/AFTER）と箇条書き5項目

**④ プログラム構成**
時刻／内容／所要 の3列テーブル。休憩行は `.break-row`（背景 `#fef8e6`、文字色 `#8a6820`）でスタイルを分ける。

**⑤ こんな方におすすめ**
山吹色の丸に白の ✓ アイコンを持つチェックリスト（3項目）。

**⑥ 持ち物・注意事項**
山吹色の小さい ● を先頭に持つリスト（4〜6項目）。

**⑦ 登壇者・スタッフ構成**
役割／人数／担当内容 の3列テーブル。

## ステップ 3: 案内ページファイルの生成

ファイル名: `annai_<slug>.html`

以下の4セクションを**必ずこの順序で**生成する。

### セクション構成

**① ヒーローセクション**
```css
background: linear-gradient(135deg, #16365C 0%, #1e4e8c 55%, #F4A300 100%);
```
- 参加者募集ラベル（白枠の丸バッジ）
- 大見出し（テーマのキャッチコピー・2行）
- サブ見出し（セミナー正式名称）
- 開催日時バッジ（半透明背景）
- 申込みボタン（山吹色・角丸50px・影付き）→ ページ内 `#apply` へ

**② 3つのポイント**
絵文字＋連番バッジ（山吹色丸）＋タイトル＋説明文 のカードを3列グリッドで配置。
モバイルでは1列に折り返す（`@media (max-width: 620px)`）。

**③ FAQ**
Q&A 形式で3問。Q は山吹色の丸バッジ（`faq-badge`）。
各 Q&A をカード（角丸16px・淡い影）で個別に包む。

**④ 申込みセクション**（`id="apply"`）
紺背景のカード。
- クロージングメッセージ（h2）
- 補足文
- 申込締切バッジ（山吹色の半透明枠）
- 申込みボタン（山吹色）
- 電話番号（小文字・薄い）

## ステップ 4: コミット＆プッシュ

両ファイルを生成後、以下を実行する。

```bash
git add kikakusho_<slug>.html annai_<slug>.html
git commit -m "{テーマ}セミナーの企画書と案内ページを作成"
git push -u origin <現在のブランチ名>
```

## 出力ルール

- 日本語で生成する
- 日時・会場・講師名など未確定情報は `○○○` または `〇〇` プレースホルダーを使う
- 金額は `1,500円` のようにカンマ区切り＋「円」で表記する
- 各ファイルはダブルクリックでそのままブラウザ表示できる完全自己完結HTMLにする
- 外部CSS・外部JS・CDN・画像URL（`src="http..."` 等）は使用禁止
- 絵文字は案内ページの3つのポイントと開催日時バッジのみで使用を絞る
- 参加者の声・FAQ・チェックリストはテーマに合った内容を生成する
