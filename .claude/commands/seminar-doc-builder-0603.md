# seminar-doc-builder-0603

## トリガー設計
このスキルは以下のワードが含まれるリクエストで起動する。他の汎用スキルや資料作成スキルとの誤発火を防ぐため、**「セミナー」と「企画」または「案内資料」が同時に含まれる場合**に限定する。

- `セミナーの企画と案内資料`
- `セミナー企画と案内資料`
- `セミナーの企画書と案内資料`
- `セミナーの企画・案内資料`
- `セミナー案内資料の作成`（＋企画の意図が文脈にある場合）

## 概要
指定されたテーマのセミナーについて、以下の2ファイルを生成してカレントディレクトリに保存し、開発ブランチへコミット・プッシュする。

1. **企画書** (`seminar_plan_<slug>.md`) — 主催者・運営者向けの内部資料
2. **案内チラシ** (`seminar_flyer_<slug>.md`) — 参加者向けの告知資料

`<slug>` はテーマを英数字・アンダースコアで表した短いラベル（例: `40_50_diet`, `sleep_quality`, `asset_management`）。

---

## ステップ 1: 入力情報の確認

ユーザーのメッセージから以下を読み取る。不足している場合はデフォルト値を使う。

| 項目 | 読み取り先 | デフォルト値 |
|------|-----------|-------------|
| テーマ | ユーザー指定 | （必須・必ず特定する） |
| 対象者 | ユーザー指定 | 一般社会人（20〜60代） |
| 開催形式 | ユーザー指定 | 会場参加＋オンライン（ハイブリッド） |
| 定員 | ユーザー指定 | 30名 |
| 参加費 | ユーザー指定 | 一般3,000円 / 早期2,000円 |

## ステップ 4: コミット＆プッシュ

両ファイルを生成後、以下を実行する。

```bash
git add seminar_plan_<slug>.md seminar_flyer_<slug>.md
git commit -m "{テーマ}セミナーの企画書と案内資料を作成"
git push -u origin <現在のブランチ名>
```

---

## 出力ルール

- 日本語で生成する
- 日時・会場・講師名など確定していない情報は `○○○` または `〇〇` のプレースホルダーを使う
- 収支計画の数字はテーマや参加費設定に合わせて調整する
- 参加者の声・FAQはテーマに即した内容にする（ダイエット以外のテーマでも「運動」「食事」ではなくそのテーマの言葉を使う）
- 絵文字は ✅ のみ使用し、他の絵文字はチラシの電話番号欄の 📞 のみ許可する
- セクション間の区切りは `---` を必ず入れる
